### Download Ultraglass

```shell copy
mkdir /etc/hyperglass
touch /etc/hyperglass/hyperglass.env
git clone https://github.com/WilhelmZA/ultraglass.git --depth=1 /opt/hyperglass
cd /opt/hyperglass
```

Clone into `/opt/hyperglass`. The sample `systemd` service runs `docker compose` from that directory. The service also reads `/etc/hyperglass/hyperglass.env`, and `systemd` does not start it if that file is missing.

<Callout type="info">The sample `compose.yaml` builds the image from source. Release images are also published as `wilhelmza/ultraglass` on Docker Hub and `ghcr.io/wilhelmza/ultraglass`, for `linux/amd64`. Each image tag is a release version without the `v`, for example `3.5.0`. The `latest` tag is the newest stable release.</Callout>

### Optional: Quickstart

Do this if you want to verify the Ultraglass page with a fake device before connecting real network devices.

```shell copy
cp /opt/hyperglass/.samples/sample_devices.yaml /etc/hyperglass/devices.yaml
cd /opt/hyperglass
docker compose up
```

Open http://localhost:8001. The first start builds the UI, which takes a few minutes.

### Create a `systemd` service

<Callout type="info">Before you create and start the Ultraglass service, verify whether you need to change any [environment variables](environment-variables.mdx).</Callout>

```shell copy
cp /opt/hyperglass/.samples/hyperglass-docker.service /etc/hyperglass/hyperglass.service
ln -s /etc/hyperglass/hyperglass.service /etc/systemd/system/hyperglass.service
systemctl daemon-reload
systemctl enable hyperglass
systemctl start hyperglass
```
