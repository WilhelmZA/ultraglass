<Steps>

### Install Dependencies

To install Ultraglass manually, install the following dependencies:

1. [Python 3.11 or later](https://www.python.org/downloads/) and [`pip`](https://pip.pypa.io/en/stable/installation/)
2. [Node.js 22.13 or later](https://nodejs.org/en/download) and [pnpm 11](https://pnpm.io/installation) for the UI build
3. [Redis 7 or later](https://redis.io/download/)
4. On Debian or Ubuntu, the UI image and favicon dependencies need `build-essential`, `pkg-config`, and `libcairo2-dev`.

On Debian or Ubuntu, install the host packages with:

```shell copy
sudo apt-get update
sudo apt-get install -y build-essential pkg-config libcairo2-dev python3-venv redis-server
```

<Callout type="warning">Make sure the Redis server is started.</Callout>

### Install Ultraglass

Once these dependencies are installed, clone and install Ultraglass with its explicit UI extra:

```shell copy
# optional: add --branch v3.5.0 to clone the latest stable release
git clone https://github.com/WilhelmZA/ultraglass --depth=1 /opt/hyperglass
cd /opt/hyperglass
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[ui]'
```

For an API-only installation, omit the `ui` extra and set `HYPERGLASS_DISABLE_UI=true`; Node.js, pnpm, and the Cairo packages are not needed in that mode.

### Create app directory

<Callout type="info">If you plan on using a different directory, set it in `HYPERGLASS_APP_PATH`. See [environment variables](environment-variables.mdx).</Callout>

```shell copy
mkdir /etc/hyperglass
touch /etc/hyperglass/hyperglass.env
```

The sample `systemd` service reads `/etc/hyperglass/hyperglass.env`. `systemd` does not start the service if that file is missing.

### Optional: Quickstart

Do this if you want to verify the Ultraglass page with default settings and a fake device.

```shell copy
cp /opt/hyperglass/.samples/sample_devices.yaml /etc/hyperglass/devices.yaml
hyperglass start
```

### Create a `systemd` service

The sample service runs the Python in the virtual environment, `/opt/hyperglass/.venv/bin/python3`. If you cloned Ultraglass to a different directory, change `ExecStart` in the `hyperglass.service` file.

```shell copy
cp /opt/hyperglass/.samples/hyperglass-manual.service /etc/hyperglass/hyperglass.service
ln -s /etc/hyperglass/hyperglass.service /etc/systemd/system/hyperglass.service
systemctl daemon-reload
systemctl enable hyperglass
systemctl start hyperglass
```

<Callout type="info">If you used a different app directory from the default `/etc/hyperglass`, change the `EnvironmentFile` value in the `hyperglass.service` file.</Callout>

</Steps>
