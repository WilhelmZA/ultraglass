The `config.yaml` file is broken into multiple sections:

## Top Level Parameters

| Parameter          | Type            | Default Value                     | Description |
| :----------------- | :-------------- | :-------------------------------- | :---------- |
| `cors_origins`     | List of Strings |                                   | Allowed CORS hosts. By default, no CORS hosts are allowed. |
| `fake_output`      | Boolean         | false                             | Return static fake output, for development and testing. |
| `org_name`         | String          | Beloved Ultraglass User           | Your organization's name. |
| `plugins`          | List of Strings |                                   | File names of common Ultraglass [plugins](/plugins) to load from the `plugins` folder of the application directory. |
| `primary_asn`      | String          | 65001                             | Your organization's primary ASN. Used to set default UI text and the PeeringDB link. |
| `request_timeout`  | Number          | 90                                | Global timeout in seconds for all requests. |
| `site_description` | String          | `{org_name}` Network Looking Glass | `<meta>` description. `{org_name}` is replaced with `org_name`. |
| `site_title`       | String          | Ultraglass                        | Browser title, also used in the API documentation title and the default terms & conditions. |

#### Example with Defaults

```yaml filename="config.yaml"
cors_origins: []
fake_output: false
org_name: Beloved Ultraglass User
plugins: []
primary_asn: 65001
request_timeout: 90
site_description: "{org_name} Network Looking Glass"
site_title: Ultraglass
```

## Caveats

### Arista EOS

The tested Arista EOS release does not supply certain route details in JSON output for `show ip bgp regex <pattern>` or `show ip bgp community <community>`. The timestamp and attached communities are absent, so Ultraglass uses the current time and an empty community list for those responses.
