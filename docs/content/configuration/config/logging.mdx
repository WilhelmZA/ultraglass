## Logging

Console, file, HTTP, and/or syslog logging configuration.

| Parameter   | Type   | Default Value | Description                                     |
| :---------- | :----- | :------------ | :---------------------------------------------- |
| `directory` | String | /tmp          | Path to directory where logs will be created.   |
| `format`    | String | text          | Log text format, must be `text` or `json`.      |
| `max_size`  | String | 50MB          | Maximum log file size before being overwritten. |
| `session_log` | Boolean | false | Write every SSH session, with each command and its output, to `<directory>/<device id>-<YYYYMMDD>.log`. Netmiko redacts the device password and secret. |

### SSH session logs

```yaml filename="config.yaml" copy
logging:
    directory: /var/log/ultraglass
    session_log: true
```

Ultraglass appends sessions to a per-device file dated in UTC. Ensure the application can write to the directory. Password redaction does not remove internal addresses or sensitive command output. Review session logs before sharing them and manage their retention separately.

For devices that reject automatic paging or terminal-width commands, set `disable_paging: false` in `devices.yaml`. Directives must then prevent paging themselves, for example with a platform-supported `| no-more` suffix.

### Query samples

`logging.samples` writes each query's request, raw device output and parsed result as one JSON line to `<directory>/hyperglass_query_log.jsonl`. It is off by default. Raw output can contain internal addresses and communities.

| Parameter        | Type    | Default Value | Description |
| :--------------- | :------ | :------------ | :---------- |
| `enable`         | Boolean | false         | Write query samples. |
| `path`           | String  |               | Output file. Defaults to `<directory>/hyperglass_query_log.jsonl`. |
| `include_raw`    | Boolean | true          | Include the raw device output. |
| `include_parsed` | Boolean | true          | Include the parsed result. |
| `max_size`       | String  | 50MB          | File size at which the file rotates to `<name>.1`. |
| `backup_count`   | Number  | 1             | Rotated files kept, `<name>.1` (newest) to `<name>.<backup_count>`. One structured full-table result can be tens of MB, so raise this for fixture capture runs. |

### Syslog

| Parameter | Type   | Default Value | Description             |
| :-------- | :----- | :------------ | :---------------------- |
| `host`    | String |               | Syslog target host.     |
| `port`    | Number | 514           | Syslog target UDP port. |

##### Syslog Example

```yaml filename="config.yaml" copy
logging:
    syslog:
        host: log.example.com
        port: 514
```

### HTTP Logging

If enabled, logs will be sent by HTTP `POST` method.

| Parameter    | Type    | Default Value | Description                                     |
| :----------- | :------ | :------------ | :---------------------------------------------- |
| `provider`   | String  | generic       | Must be `generic`, `msteams`, or `slack`.       |
| `host`       | String  |               | URL                                             |
| `headers`    | Map     |               |                                                 |
| `params`     | Map     |               |                                                 |
| `verify_ssl` | Boolean | true          | Enable or disable SSL certificate verification. |
| `timeout`    | Number  | 5             | HTTP connection timeout in seconds.             |

#### Authentication

Authentication is supported using HTTP basic authentication or an API key.

| Parameter                      | Type   | Default Value | Description                                                                                                |
| :----------------------------- | :----- | :------------ | :--------------------------------------------------------------------------------------------------------- |
| `http.authentication.mode`     | String | basic         | Must be `basic` or `api_key`.                                                                              |
| `http.authentication.username` | String |               | Basic authentication username if `mode` is set to `basic`.                                                 |
| `http.authentication.password` | String |               | Basic authentication password if `mode` is set to `basic`, or API key value if `mode` is set to `api_key`. |
| `http.authentication.header`   | String | X-API-Key     | Header name if `mode` is set to `api_key`.                                                                 |

#### Examples

##### Generic

```yaml filename="config.yaml" copy
logging:
    http:
        provider: generic
        host: https://httpbin.org
        headers:
            x-special-header: super special header value
        params:
            source: hyperglass
        verify_ssl: true
        timeout: 5
        authentication:
            mode: basic
            username: your username
            password: super secret password
```

In the example above, Ultraglass sends a `POST` request to `https://httpbin.org?source=hyperglass` with Basic Authentication headers set. The `source` value is an example identifier and can be changed for your deployment.

##### Microsoft Teams Webhook

```yaml filename="config.yaml" copy
logging:
    http:
        provider: msteams
        host: <MS Teams webhook URL>
```

##### Slack

```yaml filename="config.yaml" copy
logging:
    http:
        provider: slack
        host: <Slack webhook URL>
```

### Local Support Bundles

Use `hyperglass support-bundle` on the Ultraglass host to create a sanitized JSON file for manual attachment to a bug report. The command reads local log files only, makes no network request, and does not add a frontend endpoint or browser feature for reading source-system information.

The bundle includes Ultraglass version, basic runtime information, recent error-level log records, and failure metadata from `logging.samples`. It excludes query targets, device names, raw device output, parsed results, credentials, tokens, and filesystem paths by default. Review the file before attaching it.

```shell filename="terminal" copy
hyperglass support-bundle --output ultraglass-support-bundle.json
```

If logs are stored outside `/tmp` or the application directory, provide the directory explicitly:

```shell filename="terminal" copy
hyperglass support-bundle --log-directory /var/log/ultraglass --output ultraglass-support-bundle.json
```
