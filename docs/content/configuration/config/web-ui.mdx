## Web UI

Ultraglass provides extensive customisation options for the look and feel of the web UI.

| Parameter                   | Type   | Default Value | Description                                                                                                                                |
| :-------------------------- | :----- | :------------ | :----------------------------------------------------------------------------------------------------------------------------------------- |
| `web.location_display_mode` | String | auto          | Show the locations field as a `dropdown` or a `gallery`. `auto` uses `gallery` when there are fewer than 5 location groups and every group has fewer than 9 locations, and `dropdown` otherwise. |
| `web.custom_javascript`     | String |               | Path to a JavaScript file that is loaded in the page head. The file must exist.                                                            |
| `web.custom_html`           | String |               | Path to a custom HTML file that is rendered beneath the app. The file must exist.                                                          |
| `web.my_ip` | String | server | `server` returns the public client address using explicit proxy trust. Non-public addresses return `null`. `external` asks myip.wtf after visitor confirmation and falls back to the server endpoint if lookup fails. `off` hides the button. |

### DNS over HTTPS

By default, the browser resolves hostname targets using [DNS over HTTPS](https://www.rfc-editor.org/rfc/rfc8484). Set `web.dns_provider.name: server` to use the bounded public DNS endpoint described below.

| Parameter           | Type   | Default Value                          | Description                                                                 |
| :------------------ | :----- | :------------------------------------- | :-------------------------------------------------------------------------- |
| `web.dns_provider.name` | String | cloudflare | `cloudflare` and `google` use browser-side DNS. `server` enables `/api/dns`, which resolves public A and AAAA records through a fixed public HTTPS resolver. |
| `web.dns_provider.url`  | String | `https://cloudflare-dns.com/dns-query` | Provide a custom DNS over HTTPS URL if you'd like to use your own resolver. A URL that is not a built-in provider URL sets the provider name to `custom`. |

```yaml filename="config.yaml" copy
web:
    dns_provider:
        name: server
    my_ip: server
```

This configuration resolves public hostname targets through `/api/dns` and detects visitor addresses through `/api/myip`. The server contacts the public DNS-over-HTTPS resolver. Server My IP makes no external lookup.

Server DNS supports public A and AAAA records. Its endpoint allows 120 requests per minute per client and 600 globally. Forwarding headers require explicit proxy trust.

### Client Address

Ultraglass uses the connection address for server My IP, rate limits and webhook attribution. Forwarding headers are ignored unless the connecting peer is explicitly trusted.

| Parameter | Type | Default Value | Description |
| :-------- | :--- | :------------ | :---------- |
| `web.client_ip.header` | String | | Optional single-address header overwritten by a trusted proxy. Without this setting, Ultraglass uses the `X-Forwarded-For` chain. |
| `web.client_ip.trusted_proxies` | List of networks | `[]` | Addresses of connecting proxies. An empty list ignores all forwarding headers. |

Set `web.client_ip.header` when a CDN is in front of your reverse proxy. The reverse proxy then sees the CDN as its client, so `X-Real-IP` holds a CDN address. The CDN sends the visitor's address in its own header, such as `CF-Connecting-IP` (Cloudflare), `True-Client-IP` (Akamai) or `Fastly-Client-IP` (Fastly).

Set `web.client_ip.trusted_proxies` to the proxy addresses that connect directly to Ultraglass. Without a custom header, Ultraglass reads `X-Forwarded-For` from right to left and stops at the first untrusted address.

```yaml filename="config.yaml" copy
web:
    client_ip:
        header: CF-Connecting-IP
        trusted_proxies:
            - 192.0.2.10/32
```

<Callout type="warning">
Your reverse proxy must pass the CDN header only for requests that come from the CDN. If the proxy also accepts requests from other sources, remove the header from those requests at the proxy.
</Callout>

### Optional server lookups

The DNS and AS-path enrichment endpoints are disabled by default. Enable them explicitly in `config.yaml`, then restart Ultraglass:

```yaml
web:
    dns_provider:
        name: server
    aspath_enrichment: true
    client_ip:
        trusted_proxies: ["192.0.2.10/32"]
        # Set this only when the proxy overwrites this single-address header.
        # header: X-Real-IP
```

Replace the example proxy address with the address that actually connects to Ultraglass. An empty `trusted_proxies` list ignores all forwarding headers. Without a custom `header`, Ultraglass reads `X-Forwarded-For` from right to left, stopping at the first untrusted address. A custom header has no fallback to other headers. Configure the proxy to overwrite that header and prevent direct access to the application port.

The normal Ultraglass launcher disables Uvicorn's proxy-header rewriting so the application can verify the socket peer. When running Uvicorn directly, pass `--no-proxy-headers`. Otherwise, upstream rewriting can replace the peer before Ultraglass checks it.

Server DNS uses Cloudflare's public HTTPS resolver at `https://1.1.1.1/dns-query`. It does not use operating-system DNS, search domains, environment proxies, or redirects. Only public A and AAAA answers are returned. Internal DNS resolution is not supported by this public endpoint. Browser DNS providers keep the server endpoint disabled.

DNS permits 120 requests per client and 600 requests globally per 60-second window. AS-path enrichment permits 30 requests per client and 120 requests globally per window. Redis shares these limits across workers. Storage failures deny lookups. Both endpoints share eight outbound lookup slots and a five-second lookup deadline. The endpoints return HTTP 429 when request limits are reached and HTTP 503 when outbound capacity or required storage is unavailable.

AS-path requests accept at most 64 ASNs and an 8 KiB body. ASNs must be decimal integers between 1 and 4294967295. Duplicate ASNs are removed before lookup. Results use shared caches: DNS answers for up to 60 seconds, negative DNS responses for 15 seconds, and ASN names for one hour. Disabling `web.aspath_enrichment` also stops the AS-path modal from requesting enrichment.

### My IP and reverse-proxy upgrades

`web.my_ip: server` uses the request address for the My IP button. Non-public addresses return `null`, leaving the input unchanged. This mode does not fall back to a public IP service. Set `web.my_ip: external` explicitly to use a public IP service from the browser. That setting does not change webhook attribution.

**Upgrade requirement:** forwarding headers now require an explicitly trusted proxy. Existing nginx installations must configure `web.client_ip` to retain visitor addresses for My IP, webhook `source`, and per-client limits. An empty `trusted_proxies` list uses the socket peer, so webhooks report the proxy address until configured.

For nginx on the same host, connecting to Ultraglass over loopback, add this to `config.yaml`:

```yaml
web:
    my_ip: server
    client_ip:
        trusted_proxies: ["127.0.0.1/32", "::1/128"]
        header: X-Real-IP
```

In the nginx location that proxies requests to Ultraglass, overwrite the forwarding headers:

```nginx
location / {
    proxy_pass http://127.0.0.1:8001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

Use the configured Ultraglass port in `proxy_pass`. Keep Ultraglass bound to loopback for this setup. Restart Ultraglass and reload nginx after updating both configurations. For a container or remote proxy, trust its actual connecting address instead of loopback. Do not trust all networks. This example assumes visitors connect directly to nginx; a CDN or additional proxy requires its own explicit trust configuration in nginx.

### Logo

| Parameter          | Type             | Default Value | Description                                        |
| :----------------- | :--------------- | :------------ | :------------------------------------------------- |
| `web.logo.light`   | String           | Ultraglass light logo | Path to logo to show in light mode. |
| `web.logo.dark`    | String           | Ultraglass dark logo  | Path to logo to show in dark mode. |

```yaml filename="config.yaml" copy
web:
    logo:
        light: /path/to/light-logo.svg

        favicon: /path/to/favicon.svg
        width: 50%
```

### Greeting

The greeting is an optional modal/popup window that will present itself to users in the Web UI. It can be used for anything you want; for example:

-   A data privacy acknowledgement that must be acknowledged prior to proceeding
-   Information about your company
-   Instructions on how to use Ultraglass

| Parameter               | Type    | Default Value | Description                                                                                          |
| :---------------------- | :------ | :------------ | :--------------------------------------------------------------------------------------------------- |
| `web.greeting.enable`   | Boolean | `false`       | Enable or disable the greeting.                                                                      |
| `web.greeting.file`     | String  |               | Path to markdown or plain text file that contains greeting content. Required when `enable` is `true`. |
| `web.greeting.title`    | String  | Welcome       | Text to be used as the greeting title.                                                               |
| `web.greeting.button`   | String  | Continue      | Text to be used for the button that acknowledges/closes the greeting.                                |
| `web.greeting.required` | Boolean | `false`       | If `true`, users cannot close the modal or run any queries until the greeting has been acknowledged. |

##### Example

```yaml filename="config.yaml" copy
web:
    greeting:
        enable: true
        file: /path/to/your/file.md
        title: Welcome
        button: Continue
        required: false
```

### Highlighting

Ultraglass can highlight special values in router output and provide users with additional context. For example, an organisation's BGP communities or IP address space can be highlighted with a tooltip.

`web.highlight` is a list. Each value you wish to be highlighted is defined with the following schema:

| Parameter | Type   | Default Value | Description                                             |
| :-------- | :----- | :------------ | :------------------------------------------------------ |
| `pattern` | String |               | RegEx pattern or string to match against router output. Required. |
| `label`   | String |               | Tooltip value when the highlighted text is hovered.     |
| `color`   | String | primary       | Color name from [`web.theme.colors`](#colors).          |

##### Example

```yaml filename="config.yaml" copy
web:
    highlight:
        - pattern: "65000:1234"
          label: Special snowflake community that does a thing
          color: primary
        - pattern: '^192\.0\.2\.[0-9]+$'
          label: Magical IP Address
          color: blue
```

### Menus

Ultraglass can show customisable menus in the footer. `web.menus` is a list. By default, it contains a Terms menu and a Help menu. Setting `web.menus` replaces both. In menu content, `{site_title}`, `{org_name}` and `{version}` are replaced with their values. Each menu can be configured with the following schema:

| Parameter | Type   | Default Value | Description                                                                                                                |
| :-------- | :----- | :------------ | :------------------------------------------------------------------------------------------------------------------------- |
| `title`   | String |               | Menu title, will be the text that shows on footer.                                                                         |
| `content` | String |               | Plain text or markdown content of the menu or path to a file that contains plain text or markdown content. A value of 260 characters or more is always treated as content. |
| `side`    | String | left          | Side of the footer with which the menu will be grouped.                                                                    |
| `order`   | Number | 0             | Optionally specify an order for each menu item. If not specified, menus will be rendered in the order they are configured. |

##### Example

```yaml filename="config.yaml" copy
web:
  menus:
    - title: Terms & Conditions
      content: |
        **Don't** break stuff!
        _please_
      side: right
      order: 1
    - title: Help
      content: /path/to/help/file.md
      side: left
      order: 0
```

### Links

Ultraglass can show links to resources that users may find helpful. `web.links` is a list. By default, it contains one PeeringDB link to `https://www.peeringdb.com/asn/{primary_asn}`. Setting `web.links` replaces it. In link URLs, `{primary_asn}` is replaced with the `primary_asn` value. Each link can be configured with the following schema:

| Parameter   | Type    | Default Value | Description                                                                                                           |
| :---------- | :------ | :------------ | :-------------------------------------------------------------------------------------------------------------------- |
| `title`     | String  |               | Link text.                                                                                                            |
| `url`       | String  |               | Link URL.                                                                                                             |
| `show_icon` | Boolean | `true`        | If `true`, an icon indicating the link is an external link is shown.                                                  |
| `side`      | String  | left          | Side of the footer with which the link will be grouped.                                                               |
| `order`     | Number  | 0             | Optionally specify an order for each link. If not specified, links will be rendered in the order they are configured. |

##### Example

```yaml filename="config.yaml" copy
web:
    links:
        - title: PeeringDB
          url: https://www.peeringdb.com/asn/{primary_asn}
          show_icon: true
          side: right
          order: 1
        - title: Our Website
          url: https://example.com
          show_icon: false
          side: left
          order: 0
```

#### Title Mode

Available title modes are:

| `title_mode` Value | Action                                                              |
| :----------------- | :------------------------------------------------------------------ |
| `logo_only`        | Only the logo is displayed, no title or subtitle will be visible.   |
| `text_only`        | Only the title and subtitle are displayed, no logo will be visible. |
| `logo_subtitle`    | Only the logo and subtitle are displayed, no title will be visible. |
| `all`              | Logo, title, and subtitle will all be visible.                      |

##### Example

```yaml filename="config.yaml"
web:
    text:
        title: Our Looking Glass
        subtitle: Company Name, Inc.
        title_mode: text_only
```

#### Fonts

Ultraglass's fonts come from [Google Fonts](https://fonts.google.com/). Any Google font name may be specified to override the default fonts. When the UI is built, the server downloads the configured fonts and serves them itself, so visitors' browsers do not contact Google. If the download fails, for example on a server without internet access, the UI links Google Fonts instead.

| Parameter              | Type   | Default Value | Description                                                                              |
| :--------------------- | :----- | :------------ | :--------------------------------------------------------------------------------------- |
| `web.theme.fonts.body` | String | Nunito        | Font for all standard body text, including headings.                                     |
| `web.theme.fonts.mono` | String | Fira Code     | Font for all monospace text such as inline code or code blocks, including device output. |

##### Example

```yaml filename="config.yaml"
web:
    theme:
        fonts:
            body: Inter
```
