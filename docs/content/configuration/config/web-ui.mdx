## Web UI

Ultraglass provides extensive customisation options for the look and feel of the web UI.

| Parameter                   | Type   | Default Value | Description                                                                                                                                |
| :-------------------------- | :----- | :------------ | :----------------------------------------------------------------------------------------------------------------------------------------- |
| `web.location_display_mode` | String | auto          | Show the locations field as a `dropdown` or a `gallery`. `auto` uses `gallery` when there are fewer than 5 location groups and every group has fewer than 9 locations, and `dropdown` otherwise. |
| `web.custom_javascript`     | String |               | Path to a JavaScript file that is loaded in the page head. The file must exist.                                                            |
| `web.custom_html`           | String |               | Path to a custom HTML file that is rendered beneath the app. The file must exist.                                                          |
| `web.my_ip` | String | server | How the My IP button finds the visitor's address. `server` returns the address Ultraglass received the request from (it reads `X-Real-IP` or `X-Forwarded-For` behind a proxy), so no third party is contacted; only the address family used for the request is shown. `external` is opt-in: it asks myip.wtf, which can return both IPv4 and IPv6, after showing `web.text.ip_lookup_notice` and waiting for the visitor to confirm. If the myip.wtf lookup for a family fails, the button falls back to the server address for that family. `off` hides the button. |

### DNS over HTTPS

By default, the browser resolves hostname targets using [DNS over HTTPS](https://www.rfc-editor.org/rfc/rfc8484). Set `web.dns_provider.name: server` to use the Ultraglass server's resolver instead.

| Parameter           | Type   | Default Value                          | Description                                                                 |
| :------------------ | :----- | :------------------------------------- | :-------------------------------------------------------------------------- |
| `web.dns_provider.name` | String | cloudflare                             | If `cloudflare` or `google` are provided, no URL is necessary. Use `server` to resolve hostnames on the Ultraglass server through `/api/dns` (A and AAAA, limited to 120 requests a minute per client), for networks that block public DNS-over-HTTPS. |
| `web.dns_provider.url`  | String | `https://cloudflare-dns.com/dns-query` | Provide a custom DNS over HTTPS URL if you'd like to use your own resolver. A URL that is not a built-in provider URL sets the provider name to `custom`. |

```yaml filename="config.yaml" copy
web:
    dns_provider:
        name: server
    my_ip: external
```

This configuration resolves hostname targets through `/api/dns` and detects visitor addresses through `/api/myip`. These two features do not contact public DNS-over-HTTPS providers or myip.wtf. Font downloads and optional enrichment services have separate network requirements.

Server DNS supports A and AAAA records. Its endpoint allows 120 requests per minute per client. Server My IP returns only the address family used for the request. Configure your reverse proxy to overwrite client-address headers with verified values; both endpoints use forwarded client addresses when present.

### Logo

| Parameter          | Type             | Default Value | Description                                        |
| :----------------- | :--------------- | :------------ | :------------------------------------------------- |
| `web.logo.light`   | String           | Ultraglass light logo | Path to logo to show in light mode. |
| `web.logo.dark`    | String           | Ultraglass dark logo  | Path to logo to show in dark mode. |
| `web.logo.favicon` | String           | Ultraglass icon       | Path to icon/logo from which to generate favicons. |
| `web.logo.width`   | String           | 50%                   | Maximum width of the logo on wide screens, as a percentage from 1 to 100. The `%` sign is optional. |
| `web.logo.height`  | String           |                       | Accepted, as a percentage from 1 to 100, but not used by the current UI. |

##### Example

```yaml filename="config.yaml" copy
web:
    logo:
        light: /path/to/light-logo.svg
        dark: /path/to/dark-logo.svg
        favicon: /path/to/favicon.svg
        width: 50%
```

### Greeting

The greeting is an optional modal/popup window that will present itself to users in the Web UI. It can be used for anything you want; for example:

-   A data privacy acknowledgement that must be acknowledged prior to proceeding
-   Information about your company
-   Instructions on how to use Ultraglass

| Parameter               | Type    | Default Value | Description                                                                                          |
| :---------------------- | :------ | :------------ | :--------------------------------------------------------------------------------------------------- |
| `web.greeting.enable`   | Boolean | `false`       | Enable or disable the greeting.                                                                      |
| `web.greeting.file`     | String  |               | Path to markdown or plain text file that contains greeting content. Required when `enable` is `true`. |
| `web.greeting.title`    | String  | Welcome       | Text to be used as the greeting title.                                                               |
| `web.greeting.button`   | String  | Continue      | Text to be used for the button that acknowledges/closes the greeting.                                |
| `web.greeting.required` | Boolean | `false`       | If `true`, users cannot close the modal or run any queries until the greeting has been acknowledged. |

##### Example

```yaml filename="config.yaml" copy
web:
    greeting:
        enable: true
        file: /path/to/your/file.md
        title: Welcome
        button: Continue
        required: false
```

### OpenGraph

[OpenGraph](https://ogp.me/) controls the image, title, and description shown when you share a link. Ultraglass uses [this OpenGraph image](/opengraph.jpg) by default, but you can provide your own image. The image must be a JPEG or PNG file. Ultraglass resizes it to fit 1200 by 630 pixels and serves it as a JPEG.

| Parameter             | Type   | Default Value | Description                   |

| `web.opengraph.image` | String |               | Path to your OpenGraph image. |

### Highlighting

Ultraglass can highlight special values in router output and provide users with additional context. For example, an organisation's BGP communities or IP address space can be highlighted with a tooltip.

`web.highlight` is a list. Each value you wish to be highlighted is defined with the following schema:

| Parameter | Type   | Default Value | Description                                             |
| :-------- | :----- | :------------ | :------------------------------------------------------ |
| `pattern` | String |               | RegEx pattern or string to match against router output. Required. |
| `label`   | String |               | Tooltip value when the highlighted text is hovered.     |
| `color`   | String | primary       | Color name from [`web.theme.colors`](#colors).          |

##### Example

```yaml filename="config.yaml" copy
web:
    highlight:
        - pattern: "65000:1234"
          label: Special snowflake community that does a thing
          color: primary
        - pattern: '^192\.0\.2\.[0-9]+$'
          label: Magical IP Address
          color: blue
```

### Menus

Ultraglass can show customisable menus in the footer. `web.menus` is a list. By default, it contains a Terms menu and a Help menu. Setting `web.menus` replaces both. In menu content, `{site_title}`, `{org_name}` and `{version}` are replaced with their values. Each menu can be configured with the following schema:

| Parameter | Type   | Default Value | Description                                                                                                                |
| :-------- | :----- | :------------ | :------------------------------------------------------------------------------------------------------------------------- |
| `title`   | String |               | Menu title, will be the text that shows on footer.                                                                         |
| `content` | String |               | Plain text or markdown content of the menu or path to a file that contains plain text or markdown content. A value of 260 characters or more is always treated as content. |
| `side`    | String | left          | Side of the footer with which the menu will be grouped.                                                                    |
| `order`   | Number | 0             | Optionally specify an order for each menu item. If not specified, menus will be rendered in the order they are configured. |

##### Example

```yaml filename="config.yaml" copy
web:
  menus:
    - title: Terms & Conditions
      content: |
        **Don't** break stuff!
        _please_
      side: right
      order: 1
    - title: Help
      content: /path/to/help/file.md
      side: left
      order: 0
```

### Links

Ultraglass can show links to resources that users may find helpful. `web.links` is a list. By default, it contains one PeeringDB link to `https://www.peeringdb.com/asn/{primary_asn}`. Setting `web.links` replaces it. In link URLs, `{primary_asn}` is replaced with the `primary_asn` value. Each link can be configured with the following schema:

| Parameter   | Type    | Default Value | Description                                                                                                           |
| :---------- | :------ | :------------ | :-------------------------------------------------------------------------------------------------------------------- |
| `title`     | String  |               | Link text.                                                                                                            |
| `url`       | String  |               | Link URL.                                                                                                             |
| `show_icon` | Boolean | `true`        | If `true`, an icon indicating the link is an external link is shown.                                                  |
| `side`      | String  | left          | Side of the footer with which the link will be grouped.                                                               |
| `order`     | Number  | 0             | Optionally specify an order for each link. If not specified, links will be rendered in the order they are configured. |

##### Example

```yaml filename="config.yaml" copy
web:
    links:
        - title: PeeringDB
          url: https://www.peeringdb.com/asn/{primary_asn}
          show_icon: true
          side: right
          order: 1
        - title: Our Website
          url: https://example.com
          show_icon: false
          side: left
          order: 0
```

#### Title Mode

Available title modes are:

| `title_mode` Value | Action                                                              |
| :----------------- | :------------------------------------------------------------------ |
| `logo_only`        | Only the logo is displayed, no title or subtitle will be visible.   |
| `text_only`        | Only the title and subtitle are displayed, no logo will be visible. |
| `logo_subtitle`    | Only the logo and subtitle are displayed, no title will be visible. |
| `all`              | Logo, title, and subtitle will all be visible.                      |

##### Example

```yaml filename="config.yaml"
web:
    text:
        title: Our Looking Glass
        subtitle: Company Name, Inc.
        title_mode: text_only
```

```yaml filename="config.yaml"
web:

            cyan: "#00ffff"
```

#### Fonts

Ultraglass's fonts come from [Google Fonts](https://fonts.google.com/). Any Google font name may be specified to override the default fonts. When the UI is built, the server downloads the configured fonts and serves them itself, so visitors' browsers do not contact Google. If the download fails, for example on a server without internet access, the UI links Google Fonts instead.

| Parameter              | Type   | Default Value | Description                                                                              |
| :--------------------- | :----- | :------------ | :--------------------------------------------------------------------------------------- |
| `web.theme.fonts.body` | String | Nunito        | Font for all standard body text, including headings.                                     |
| `web.theme.fonts.mono` | String | Fira Code     | Font for all monospace text such as inline code or code blocks, including device output. |

##### Example

```yaml filename="config.yaml"
web:
    theme:
        fonts:
            body: Inter
```
