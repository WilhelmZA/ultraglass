To get started, Ultraglass only needs to know about your devices.

<Callout type="info">
    **Devices** are your routers, switches, or whatever else you want to call the endpoints
    Ultraglass will query for information.
</Callout>

## Simple Device Configuration

```yaml filename="devices.yaml"
devices:
    - name: NYC Router 1
      address: <IP address Ultraglass will use to log into the router>
      credential:
          username: <Username Ultraglass will use to log into the router>
          password: <Password Ultraglass will use to log into the router>
      platform: cisco_ios
      attrs:
          source4: <IPv4 address from which to source ping & traceroute commands>
          source6: <IPv4 address from which to source ping & traceroute commands>
```

For BGP community queries on Cisco IOS, the router may also need `ip bgp-community new-format`. See [Cisco IOS BGP communities](/platforms.mdx#cisco-ios-bgp-communities).

That's it!
